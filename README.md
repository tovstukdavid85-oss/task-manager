# Task Manager

Учебный проект серверного приложения для управления задачами на Java и Spring Boot.

## О проекте

Task Manager задуман как приложение для организации задач: хранения описания, статуса, приоритета и срока выполнения, а также группировки задач по категориям и связи с пользователями.

> **Статус:** проект находится в разработке. Не все компоненты и REST API завершены; сборку и работоспособность необходимо проверить перед запуском.

## Технологии

- **Java**
- **Spring Boot**
- **Spring Web** — основа для HTTP/REST API
- **Spring Data JPA / Hibernate** — взаимодействие с реляционной базой данных
- **PostgreSQL** — хранение данных
- **Maven** — управление зависимостями и сборка
- **Docker Compose** — конфигурация запуска базы данных в контейнере
- **Lombok** — сокращение шаблонного Java-кода

Точные версии и настройки смотрите в `pom.xml` и `docker-compose.yml`.

## Предусмотренная модель данных

- **User** — пользователь приложения.
- **Task** — задача с названием, описанием, статусом, приоритетом и сроком.
- **Category** — категория для группировки задач.

Предусмотренные статусы задачи: `PENDING`, `IN_PROGRESS`, `COMPLETED`, `CANCELLED`.

## Структура репозитория

- `pom.xml` — зависимости и настройки сборки Maven.
- `src/` — исходный код приложения.
- `docker-compose.yml` — конфигурация контейнеров.
- `Dockerfile` — конфигурация сборки образа приложения.
- `ddl_User.sql` — SQL-скрипт для таблицы пользователей.
- `mvnw` / `mvnw.cmd` — Maven Wrapper для Unix-подобных систем и Windows.

## Подготовка к запуску

Необходимы установленный **JDK совместимой версии** и **Docker Desktop** (если база данных запускается в Docker).

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/tovstukdavid85-oss/task-manager.git
   cd task-manager
   ```

2. Откройте проект в IntelliJ IDEA и проверьте настройки JDK в `pom.xml`.

3. Проверьте `docker-compose.yml`: параметры базы данных, порты и переменные окружения. Не публикуйте реальные пароли и токены в репозитории.

4. Запустите сервис базы данных согласно конфигурации Docker Compose.

5. Проверьте и исправьте ошибки компиляции, затем попробуйте собрать проект в Windows:

   ```powershell
   .\mvnw.cmd clean package
   ```

   На Linux/macOS:

   ```bash
   ./mvnw clean package
   ```

Поскольку проект ещё в разработке, эти шаги не гарантируют успешный запуск без дополнительной настройки и исправлений.

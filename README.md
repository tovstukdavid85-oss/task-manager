# Task Manager

Учебный backend-проект для управления задачами, разработанный на **Java 21** с использованием **Spring Boot**. Проект помогает практиковаться в создании REST API, работе с базой данных PostgreSQL и построении типичной многослойной архитектуры Java-приложения.

## Возможности

- Создание задач.
- Получение списка всех задач и отдельной задачи по ID.
- Обновление существующей задачи.
- Удаление задачи.
- Хранение данных в PostgreSQL.
- Запуск базы данных через Docker Compose.

Основные REST-операции с задачами доступны по адресу `/api/tasks`.

## Технологический стек

- **Java 21** — язык разработки.
- **Spring Boot** — основа серверного приложения.
- **Spring Web** — создание REST API.
- **Spring Data JPA / Hibernate** — работа с данными.
- **PostgreSQL** — реляционная база данных.
- **Maven** — сборка проекта и управление зависимостями.
- **Docker Compose** — запуск PostgreSQL в контейнере.
- **Lombok** — сокращение шаблонного кода Java.

## Модель данных

- **Task** — задача: название, описание, статус, приоритет, срок выполнения и связанные сущности.
- **User** — пользователь, связанный с задачами.
- **Category** — категория для группировки задач.

## Архитектура

Проект использует разделение ответственности по слоям:

- `controller` — принимает HTTP-запросы и возвращает ответы API.
- `service` — содержит бизнес-логику.
- `repository` — взаимодействует с базой данных через Spring Data JPA.
- `model` — сущности предметной области.
- `dto` — объекты для передачи данных в API.

## Запуск локально

### Что понадобится

- JDK 21.
- IntelliJ IDEA или другая Java IDE.
- Docker Desktop.

### 1. Клонировать репозиторий

```bash
git clone https://github.com/tovstukdavid85-oss/task-manager.git
cd task-manager
```

### 2. Запустить базу данных

Убедитесь, что Docker Desktop запущен, затем выполните в терминале проекта:

```bash
docker compose up -d
```

### 3. Проверить настройки подключения

Настройки PostgreSQL находятся в `src/main/resources/application.yml`. При необходимости задайте переменные окружения `DB_URL`, `DB_USERNAME` и `DB_PASSWORD`. Не храните реальные пароли в публичном репозитории.

### 4. Собрать проект

В Windows PowerShell:

```powershell
.\mvnw.cmd clean verify
```

В Linux/macOS:

```bash
./mvnw clean verify
```

### 5. Запустить приложение

Откройте проект в IntelliJ IDEA, выберите конфигурацию Spring Boot и запустите приложение. При успешном старте сервер использует порт `8080`.

## Примеры API

Базовый путь: `/api/tasks`.

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/api/tasks` | Получить список задач |
| GET | `/api/tasks/{id}` | Получить задачу по ID |
| POST | `/api/tasks` | Создать задачу |
| PUT | `/api/tasks/{id}` | Обновить задачу |
| DELETE | `/api/tasks/{id}` | Удалить задачу |

Для создания и обновления задачи передавайте JSON в соответствии с полями DTO проекта.
